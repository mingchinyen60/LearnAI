📊 資訊圖解：Git 的「四大空間流動圖」

觀念核心圖解

很多初學者被 add、commit、push 搞糊塗。其實只要理解檔案在四個房間的「搬家過程」即可：

💡 記憶口訣： 寫完代碼 (工作目錄) ➔ 挑選要存檔的檔案 `git add` (打包放進箱子) ➔ 封箱並貼上存檔標籤 `git commit` (遊戲存檔點) ➔ 送上雲端保險箱 `git push` (同步到 GitHub)。
📦

什麼是 Git？

  • ✓ 本機工具：不安裝網路也能在自己電腦上記錄每一個版本變化。
  • ✓ 微型時光機：追蹤檔案增加、刪減了哪幾行，支援秒級復原。
  • ✓ 由 Linux 創始人 Linus Torvalds 所開發的自由開源版本控制系統。
🐙

什麼是 GitHub？

  • ✓ 雲端平台：專門存放 Git 倉庫的全球最大程式碼代管服務（微軟旗下）。
  • ✓ 工程師的社群履歷：展現開源專案、分享作品、找共同開發夥伴。
  • ✓ 自動化部署跳板：可直接綁定 Vercel、Netlify 或 GitHub Pages 自動發布網頁！

🛠️ 新專案起步：建立人生的第一個「時光存檔點」

當你在 IDE（如 Cursor、VS Code 或 Antigravity）跟 AI 一起生成了一個小專案，第一件事就是替它拍照存檔。

第 1 步：設定你的作者身分（每台電腦只需做一次）

告訴 Git 每次存檔是由誰完成的：

git config --global user.name "你的名字或暱稱"
git config --global user.email "your-email@example.com"

第 2 步：在專案資料夾啟動時光機 (`git init`)

開啟終端機（Terminal）並在當前專案資料夾下執行：

git init
💡 執行後會在資料夾內建立一個隱藏的 .git 資料夾，這就是時光機的核心大腦！

第 3 步：把檔案打包並正式存檔 (`git add` & `git commit`)

將專案內所有的初始代碼收入暫存區，並按下存檔鍵：

# 1. 檢查目前狀態 (哪些檔案有被動過)
git status

# 2. 將所有檔案加入暫存區 (打包)
git add .

# 3. 建立正式存檔點，並寫下一句易懂的說明
git commit -m "feat: 初版專案完成，AI 協作建立首頁"

親自觸摸時光機的脈動

請開啟終端機，依序執行下列指令建立練習專案並查看存檔歷程： 

# 建立測試目錄並進入

# 初始化 Git

# 建立一個測試檔案

# 加入暫存並存檔

# 觀看存檔歷史 (這就是你的時光履歷！)

🛡️ 防護罩一：建立 .gitignore 隔離機密

資安生死線

.gitignore 是 Git 的黑名單清單。只要寫在裡面的檔名，Git 就會視而不見，永遠不會被上傳到 GitHub！

❌ 致命危險做法

直接把金鑰寫在 .env 且沒有忽略，直接推上公開 GitHub 倉庫。

OPENAI_API_KEY="sk-proj-xxxxxx..." ➔ 慘遭機器人盜刷數千美元！
✅ 正確黃金準則

1. 在 .gitignore 加入 .env
2. 另外放一個不含密碼的 .env.example 供參考。

OPENAI_API_KEY="your_api_key_here" ➔ 安全無虞！

標準 Vibe Coding 專案必備 `.gitignore` 範例：

# 機密環境變數檔 (重要：保護 API 金鑰)
.env
.env.local
.env.*.local

# 相依套件庫 (不需要上傳，由 npm/pip 安裝即可)
node_modules/
venv/
__pycache__/

# 系統與編輯器快取
.DS_Store
Thumbs.db
.vscode/*
!.vscode/settings.json

🩺 防護罩二：「救命！AI 把代碼改爛了」四大急救指引

隨時還原

情境 1：AI 到底偷改了什麼？

比較當前檔案與上次存檔的差異（紅色代表被刪掉，綠色代表新增加）。

git diff

情境 2：AI 剛剛寫爛了，立刻放棄修改！

只要還沒 commit，這條指令能讓你瞬間回到上一次存檔的乾淨狀態：

# 還原單一檔案
git restore index.html

# 放棄全部未存檔的修改 (慎用：全數還原！)
git restore .

情境 3：不想放棄修改，但想先暫存起來抽屜放著

就像把未完成的拼圖先推進抽屜，等一下想看隨時能拿出來：

# 收進暫存抽屜 (工作區回到乾淨狀態)
git stash

# 稍後想拿出來繼續用
git stash pop

情境 4：已經手滑 commit 了，但想反悔存檔？

取消上一次的 commit，但保留你寫好的檔案內容供重新整理：

# 拆解上一次的存檔，檔案原封不動留在工作區
git reset --soft HEAD~1

親自體驗「安全一鍵還原」的威力

模擬「程式碼被胡亂改壞」的場景，並使用 git restore 把它變回完好如初： 

# 故意把剛才存檔的 README.md 內容全改壞
echo "壞掉的代碼！！！ERROR 404！！！" > README.md

# 檢查狀態，會看到紅色標示檔案已被修改
git status

# 觀察差異

# 發動救命魔法：瞬間還原！
git restore README.md

# 再次查看檔案內容，原本的文字完好如初！
cat README.md

🌿 平行宇宙分支法 (Branching)：給 AI 一個隨便搞破壞的沙盒

當你的專案現在運作良好，但你想請 AI 嘗試一個「超級大規模重構」或「實驗性新功能」，請記住 Vibe Coding 的第一守則：
👉 永遠不要直接在 `main` 主線分支上叫 AI 嘗試！先開一條新分支，就是開啟了一個安全的平行宇宙。

1. 建立並切換到新分支 (`git switch -c`)

一秒切換進入平行宇宙，接下來所有存檔都不會影響穩定版：

# 建立並直接切換至新分支
git switch -c feature/ai-redesign

# 查看目前所在分支 (打 * 號代表當前位置)
git branch

2. 驗收結果：合併 vs 瀟灑丟棄

測試滿意就吸收進主幹，不喜歡就直接整支丟垃圾桶：

# 切回主幹
git switch main

# 情況 A：成果超棒，合併進來！
git merge feature/ai-redesign

# 情況 B：AI 改得亂七八糟？直接強制刪除！
git branch -D feature/ai-redesign

開闢分支並進行一次零負擔的合併

請在練習專案中切換分支、增加新功能檔案並成功合併回 `main`： 

# 1. 建立並切換到 feature/new-style 分支
git switch -c feature/new-style

# 2. 新增一個樣式檔案並存檔
echo "body { background: #fafafa; }" > style.css
git add style.css
git commit -m "style: 加入背景樣式"

# 3. 切回主幹 main
git switch main

# 4. 合併新功能！
git merge feature/new-style

# 5. 任務完成後刪除過渡分支
git branch -d feature/new-style

☁️ 把代碼推向雲端：GitHub 遠端串接與自動部署

把本機的 Git 倉庫推送到 GitHub，不僅是最好的雲端保險箱，還能讓全世界的朋友瀏覽你的 Vibe Coding 成果！

步驟 1：在 GitHub 網站上建立新倉庫 (Repository)

  1. 登入 GitHub.com，點選右上角的 「+」 ➔ 「New repository」。
  2. 輸入倉庫名稱（例如 my-first-vibe-app）。
  3. 選擇 Public（公開，任何人看得到）或 Private（私人，僅自己與受邀者看得到）。
  4. ⚠️ 注意：如果你本機已經有檔案，不要勾選「Add a README file」或「Add .gitignore」，避免造成歷史衝突。
  5. 點選綠色按鈕 「Create repository」。

步驟 2：綁定遠端並推送 (Push) 上雲端

在 GitHub 建立成功後，複製給你的遠端網址，並在你的本機終端機貼上執行： 

# 1. 確保目前主分支名稱為 main
git branch -M main

# 2. 加入遠端倉庫地址 (將網址替換為你自己的 GitHub 網址)
git remote add origin https://github.com/你的帳號/my-first-vibe-app.git

# 3. 第一次推送全部代碼，並綁定預設上游分支 (-u)
git push -u origin main
💡 以後每次本機有新的 commit 存檔，只要簡短輸入 git push 就能自動同步上雲端！
🚀

步驟 3：一鍵公開你的作品！免費部署兩大神器

Vibe Coding 最有成就感的時刻，就是把做好的網頁給朋友把玩！透過 GitHub 連動，完全不需要花錢買伺服器：

方案 A：GitHub Pages (純靜態網頁)

進入 GitHub Repo ➔ Settings ➔ Pages ➔ Branch 選擇 `main` 儲存。2 分鐘內即可獲得 https://帳號.github.io/專案名 專屬公開網址！

方案 B：Vercel / Netlify (現代全端應用)

登入 Vercel 用 GitHub 帳號一鍵登入，點擊「Import」你的 Repo，每次 git push，Vercel 就會自動幫你打包並重新上線最新版！

檢查與管理遠端連線狀態

學會如何確認目前專案到底連到了哪一個 GitHub 遠端位址： 

# 檢查目前的遠端連接資訊 (顯示 Fetch 與 Push 位址)
git remote -v

# 若想要拉取雲端上的最新修改 (若有其他電腦或協作者更動)
git pull
