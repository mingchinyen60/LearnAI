# 🚀 Git & GitHub 自學指南 (Vibe Coding 特製版)

專為 **Vibe Coding（AI 協作開發者）** 設計的繁體中文視覺化自學手冊與技能工具庫。

---

## 📖 專案內容簡介

* **`index.html`**：完整的單一純 HTML 互動自學教材。
  * **分頁籤導航 (Tabs)**：心態觀念、環境與初次存檔、兩大安全防護罩（API 防外洩與 AI 改爛急救）、平行宇宙分支法、GitHub 雲端備份與自動部署、精選影音與互動學習庫、急救速查卡。
  * **內嵌 SVG 資訊圖表**：直覺展示四大空間流向與分支實驗流程。
  * **Try This 實戰演練**：具備任務引導、完成進度追蹤與打勾狀態保存。
  * **一鍵複製指令按鈕**：方便隨時貼到終端機執行。
* **`.agents/skills/self-learn-new-tech/`**：
  * 固化提煉的新技術自學標準 SOP（Meta-Skill），日後可自動套用至任何新技術（如 Docker、Next.js、Vector DB 等）並產出同等規格教材。

---

## 🖥️ 如何使用教材

直接在瀏覽器中開啟 [index.html](index.html) 即可離線閱讀與演練，或透過 GitHub Pages 一鍵發布至線上！
